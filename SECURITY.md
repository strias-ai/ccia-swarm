# Seguridad

No subas claves privadas, tokens, secretos de webhook, IBAN ni otros datos financieros a este repositorio.

Si un secreto llega a una rama pública, considéralo comprometido: revócalo o rótalo primero, elimina la copia actual y después evalúa limpiar el historial. Para informar de un problema de seguridad, abre una incidencia sin incluir el secreto.
