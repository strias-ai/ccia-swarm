# Herramienta Multi-archivo para Consultar Latencia y Estado de URLs Web

Esta herramienta es una solución multi-archivo diseñada para facilitar la consulta de la latencia y el estado de múltiples URLs web. Utiliza técnicas de manejo de excepciones y exporta las métricas a un archivo de registro para facilitar el seguimiento y análisis.

## Funcionalidades Principales

1. **Consulta de URLs Web**: Permite la consulta de la latencia y el estado de múltiples URLs web de una sola vez.
2. **Manejo de Excepciones**: Implementa un sistema de manejo de excepciones para manejar errores de red, tiempo de espera y otros problemas
