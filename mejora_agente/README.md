# README.md

## Proyecto: Recogida de Recursos del CCIA

Este proyecto tiene como objetivo que los agentes del CCIA sepan qué recursos tienen. Para ello, se deben recoger los recursos de software y hardware.

### Recursos a Recoger

Los recursos que se deben recoger son:

- Software
- Hardware

### Cómo Recoger los Recursos

Para recoger los recursos, se debe analizar el sistema operativo.

### Ejecución del Proyecto

Para ejecutar el proyecto, se debe utilizar el siguiente comando:

```bash
python3 proyecto.py
```

Este comando ejecutará el proyecto sin necesidad de interactuar con el usuario.
